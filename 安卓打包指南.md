# 📱 安卓APK打包指南

## 方案一：PWA安装（最简单，推荐）

### 步骤
1. 确保服务器已启动（`聊天平台-启动.bat`）
2. 手机浏览器访问 `http://你的IP:8000`
3. 点击浏览器菜单 → "添加到主屏幕" 或 "安装应用"
4. 完成！桌面会出现聊天平台图标

### 优点
- 无需打包，直接使用
- 自动更新
- 占用空间小

---

## 方案二：使用Capacitor打包APK

### 前置要求
- Node.js 18+
- Android Studio
- Java JDK 17+

### 打包步骤

```bash
# 1. 创建Capacitor项目
npm init @capacitor/app
npm install @capacitor/core @capacitor/cli

# 2. 初始化Capacitor
npx cap init "聊天平台" "com.chat.app" --web-dir ../frontend

# 3. 添加Android平台
npm install @capacitor/android
npx cap add android

# 4. 同步Web文件
npx cap sync

# 5. 打开Android Studio
npx cap open android

# 6. 在Android Studio中
# - Build → Generate Signed Bundle/APK
# - 选择APK
# - 创建或选择签名密钥
# - 选择release版本
# - 完成打包
```

## 方案三：在线打包服务

### PWABuilder（推荐）
1. 访问 https://www.pwabuilder.com/
2. 输入你的服务器地址
3. 点击 "Package for stores"
4. 选择 Android
5. 下载生成的APK

### Gonative.io
1. 访问 https://gonative.io/
2. 输入网站URL
3. 配置应用信息
4. 下载APK

## 方案四：使用Android Studio手动打包

### 前置要求
- Android Studio
- Java JDK 17+

### 步骤

1. **创建WebView应用**

创建 `app/src/main/java/com/chat/app/MainActivity.java`:
```java
package com.chat.app;

import android.os.Bundle;
import android.webkit.WebView;
import android.webkit.WebViewClient;
import android.webkit.WebSettings;
import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {
    private WebView webView;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        
        webView = new WebView(this);
        setContentView(webView);
        
        WebSettings settings = webView.getSettings();
        settings.setJavaScriptEnabled(true);
        settings.setDomStorageEnabled(true);
        settings.setAllowFileAccess(true);
        
        webView.setWebViewClient(new WebViewClient());
        webView.loadUrl("http://localhost:8000");
    }

    @Override
    public void onBackPressed() {
        if (webView.canGoBack()) {
            webView.goBack();
        } else {
            super.onBackPressed();
        }
    }
}
```

2. **配置AndroidManifest.xml**
```xml
<?xml version="1.0" encoding="utf-8"?>
<manifest xmlns:android="http://schemas.android.com/apk/res/android">
    
    <uses-permission android:name="android.permission.INTERNET" />
    <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
    
    <application
        android:allowBackup="true"
        android:icon="@mipmap/ic_launcher"
        android:label="聊天平台"
        android:theme="@style/Theme.AppCompat.NoActionBar">
        
        <activity
            android:name=".MainActivity"
            android:exported="true">
            <intent-filter>
                <action android:name="android.intent.action.MAIN" />
                <category android:name="android.intent.category.LAUNCHER" />
            </intent-filter>
        </activity>
    </application>
</manifest>
```

3. **打包APK**
- Build → Generate Signed Bundle/APK
- 选择APK → Next
- 创建密钥或选择现有密钥
- 选择release → Finish

## 注意事项

1. **服务器地址配置**
   - 如果服务器在局域网，需要使用局域网IP
   - 如果要外网访问，需要配置端口映射或使用云服务器

2. **HTTPS要求**
   - PWA安装需要HTTPS（localhost除外）
   - 可以使用Cloudflare Tunnel免费获取HTTPS

3. **权限配置**
   - 网络权限：INTERNET
   - 存储权限（如需文件上传）：READ_EXTERNAL_STORAGE
